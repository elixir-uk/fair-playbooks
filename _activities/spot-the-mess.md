This game uses Data Carpentry's messy spreadsheet exercise as it is. Download the data from the [lesson page](https://datacarpentry.github.io/spreadsheet-ecology-lesson/01-format-data.html) (direct link: [messy survey data on Figshare](https://ndownloader.figshare.com/files/2252083)). This page adds a quick run-sheet and a stand sign.

## How to run it (15–20 min)

1. **Set it up (2 min).** Make sure each pair has the file open in a spreadsheet program. The data is survey records from an ecology study, with tabs for 2013 and 2014.
2. **Hunt (10 min).** Give Data Carpentry's instructions: with the person next to you, identify what is wrong with this spreadsheet, and discuss the steps you would need to take to clean up the 2013 and 2014 tabs and put them together in one spreadsheet. Remind them to create a new file or tab for the cleaned data and never to change the original.
3. **Share back (5 min).** Go round the room. Each pair names one problem nobody else has mentioned yet. Tally them on the board.
4. **Wrap up (3 min).** Show Data Carpentry's [common spreadsheet errors](https://datacarpentry.github.io/spreadsheet-ecology-lesson/02-common-mistakes.html) and tick off the ones the room found.

## Debrief questions

- If this landed in your inbox in two years, could you use it?
- Which of these mistakes do you see in your own spreadsheets?
- Which would stop a computer reading the data, and which would stop a person understanding it?

## Facilitator tip

Data Carpentry's own guidance is to use the common errors page only as a reference for discussion, not to walk through it. Don't try to cover the whole list. If a pair stalls, point them to one tab and ask what they'd need to change to combine it with the other.

## Run it as a drop-in stand

Print one tab of the messy spreadsheet as a big poster (A1 or A2, or four A3 sheets taped together) in a faculty foyer or atrium, and let passers-by find the problems.

- **Bring:** the poster, sticky notes, pens, the sign below, and the common errors list printed on a separate sheet.
- **Set up:** put the poster at eye level with sticky notes and pens next to it. Keep a running tally on the sign.
- **A visit:** spot a problem, write it on a sticky note and stick it where it is. Most people stop to read what others have found, then try to find one nobody has spotted yet.
- **Keep it going:** update the tally through the day. Pin up the common errors list at the end of the day, or at a set time ("Answers at 3pm") to bring people back.
- **Follow up:** put a poster from the [promo kit]({{ '/promo/' | relative_url }}) next to the stand with a QR code for your next session.

## Make it yours

Data Carpentry's dataset is ecology survey data, but the mistakes are the same in any field. If your audience works with very different data, you can use a messy table from your own institution instead, keeping the same kinds of mistake. Module 03 uses an imaging example from EuroBioimaging training material.
