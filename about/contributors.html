Contribute

Ran a module and changed something that worked better? Spotted a mistake or a broken link? Open an issue on GitHub or send a pull request. If you'd like to write a new module, How to write a module explains the format and everything a slide can show.

Contributions are shared under the same CC BY 4.0 licence as the rest of the playbook.
