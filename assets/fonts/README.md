# Fonts used by the promo poster generator

Self-hosted so `assets/js/promo.js` can embed them into downloadable PNG
posters (a browser can only draw web fonts into an image if it can read the
font file itself). The site pages still load these fonts from Google Fonts.

| File | Font | Licence |
|---|---|---|
| `lato-400.woff2`, `lato-900.woff2` | Lato, by Łukasz Dziedzic (latin subset) | SIL Open Font License 1.1 |
| `press-start-2p.woff2` | Press Start 2P, by CodeMan38 (latin subset) | SIL Open Font License 1.1 |

Both licences allow use, embedding and redistribution: https://openfontlicense.org
